## เดโม Neo4j (ปัญจพล, 3 นาที)
**ก่อนขึ้นเวที (วันก่อนและเช้าวันนำเสนอ)**
1. เข้า console.neo4j.io → instance ของทีม → ถ้าขึ้น Paused ให้กด **Resume** (รอ 1–3 นาที)
2. ถ้าเพิ่งสร้าง instance ใหม่ ให้รัน `Freight_GraphDB_Neo4j.ipynb` หนึ่งครั้งเพื่อโหลดข้อมูล
3. เปิด **Query** ใน Aura console ค้างไว้ในแท็บ และเตรียมภาพหน้าจอผลไว้สำรองเผื่อเน็ตล่ม

**ระหว่างเดโม**
1. (0:30) อธิบาย schema: จุดคือจังหวัด ฐานมีป้าย Hub เส้น SHIPS_TO แยกตามสินค้า และ REACHES คือจังหวัดในรัศมี 150 กม. รัน `CALL db.schema.visualization()`
2. (1:15) CQ1 งานขากลับ: รถรับงานใกล้ฐานหนึ่ง ส่งของถึงจังหวัดที่อยู่ใกล้ฐานไหน
```cypher
MATCH (h1:Hub)-[:REACHES]->(a:Province)-[s:SHIPS_TO]->(b:Province)<-[:REACHES]-(h2:Hub)
RETURN h1.name AS pickup_hub, h2.name AS delivery_hub, sum(s.trips) AS trips ORDER BY trips DESC
```
3. (1:15) CQ2 รถจากแต่ละฐานไปจบที่ไหน (ที่ที่ทีมขายควรหางานขากลับ)
```cypher
MATCH (h:Hub)-[:REACHES]->(a:Province)-[s:SHIPS_TO]->(b:Province)
WITH h, b, sum(s.trips) AS trips ORDER BY trips DESC
WITH h, collect({dest:b.name, trips:trips})[..5] AS top
UNWIND top AS t RETURN h.name AS hub, t.dest AS destination, t.trips AS trips
```
ปิดด้วย: "ยอดรวมในฐานข้อมูลตรงกับ notebook ทุกตัว เราตรวจด้วย assert"
